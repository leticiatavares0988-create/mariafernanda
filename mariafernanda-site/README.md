# Studiova

Landing page baseada no template Studiova (WrapPixel, MIT), convertida para Next.js 15 + React 19.

## Rodar

```bash
npm install
npm run dev
```

Abre em http://localhost:3000.

## Deploy

Suba o repositório no GitHub e importe na Vercel. Nenhuma configuração extra é necessária.

## Estrutura

- `app/` layout, página e o CSS compilado do template
- `components/` uma seção por componente
- `public/assets/images/` imagens e vídeo do template
- `scss/` fontes Sass originais, caso queira recompilar `app/styles.css`

Fonte original: https://github.com/wrappixel/studiova-bootstrap-template
